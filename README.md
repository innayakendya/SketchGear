# SketchGear

Intelligent Vectorization engine for 2D/3D modeling and graphics editing, optimized for cross-platform interface deployment.

SketchGear is aimed at developers who need a straightforward, dependable solution.

**Highlights**

- Intelligent Vectorization engine for 2D/3D
- modeling and graphics editing, optimized
- for cross-platform interface deployment

## Key Features

- Intelligent Vectorization engine for 2D/3D
- modeling and graphics editing, optimized
- for cross-platform interface deployment

## Technology Stack

- php
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/innayakendya/SketchGear.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
